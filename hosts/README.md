# Hosts <img style="margin: 6px 13px 0px 0px" align="left" src="../art/logo_36x36.png" />

Hosts are independent system configurations for physical or virtual machines. Each host is a
real `nixosConfigurations.<hostname>` entry in the single root `flake.nix`, generated from its
`hosts/<hostname>/` directory: `configuration.nix`, `hardware-configuration.nix` and local sops
encrypted secrets `args.enc.json`. The `nixos-config` repo is a single flake with supporting options,
modules and layers that are used to compose the different hosts being managed - there is nothing
host-specific to stage or link at the repo root; `nix build .#<hostname>` (or `clu build
<hostname>`) selects the host directly as a flake attribute. At the top level of the repo there are
reusable shared flake arguments that can be overridden at the host level if specific customization
is desired. This setup makes it both reusable, composable and customizable per host as needed while
still retaining complete versioned declarative behavior.

## Shared setup
The root of the project provides a set of reusable shared flake configuration and arguments that may 
be used to compose and manage a host or overridden as necessary.

* `flake.nix` / `flake.lock` - the single shared flake for every host (only macbook needs an extra
  input, `nixos-hardware`, declared unconditionally here since flake inputs can't be conditional)
* `args.enc.json` - sops encrypted arguments to be shared by all hosts or overridden locally
* `args.nix` - non-private arguments to be shared by all hosts or overridden locally

## Host setup
Each host in `nixos-config/hosts/` is composed of:
* `configuration.nix` for the main host configuration
* `hardware-configuration.nix` generated by `nixos-generate-config` during install
* `args.enc.json` sops encrypted arguments which override `nixos-config/args.enc.json`
* `secrets.enc.yaml` runtime secrets decrypted by sops-nix at activation (never touches the Nix store)

## Build-time args
Before evaluation, `clu` decrypts just the target host's build-time args (root `args.enc.json` +
`hosts/<hostname>/args.enc.json`) to `args.dec.json` and git-stages them (`git add -f`) - Nix
flakes only see git-tracked/staged files, and some of these values (drive UUIDs, network interface
config, EFI/MBR selection) genuinely have to be visible to NixOS module options at evaluation time, so
there's no way around staging them without `--impure`. This is scoped to exactly one host per build
and reverted (unstaged + deleted from disk) immediately after via a `trap ... EXIT`, so a crash or
`kill -9` mid-build leaves at most that one host's plaintext behind - run `clu clean dec` to sweep up
any leftovers.

Values that are only ever consumed by a running service reading a file at runtime (not by a NixOS
module option at evaluation time) don't need this treatment at all - see how `host.smb.secrets` /
`options/services/raw/smb` already renders SMB credentials via `sops.templates`, decrypted straight to
`/etc/smb/secrets/<share>` at activation by sops-nix, the same as `host.secrets` does for the user
password hash.

## Host Args
The top level `args.nix` and sops encrypted`args.enc.json` along with the local sops encrypted 
`args.enc.json` argument files provide a mechanism for rapidly specifying bulk reusable configuration 
across many hosts.

### Accepted args.enc.json values
The supported arguments listed below are used throughout my configuration from the specialArgs 
inclusion that I've named `args` throughout my configuration.

| Argument                  | Type  | Default           | Description
| ------------------------- | ----- | ----------------- | --------------------------------------
| `target`                  | str   | `layers/bundles/xfce-desktop.nix` | Only used by `nixosConfigurations.install` to bootstrap a brand new host before it has a `hosts/<hostname>` directory
| `hostname`                | str   | `nixos`           | Not settable for real hosts - always the `hosts/<hostname>` directory name; this default only applies to `nixosConfigurations.install`/`iso`
| `id`                      | str   |                   | `dbus-uuidgen` generated Machine ID to use for the system
| `efi`                     | bool  | `false`           | EFI system boot type set during installation
| `mbr`                     | str   | `nodev`           | MBR system boot device set during installation, e.g. `/dev/sda`
| `arch`                    | str   | `x86_64-linux`    | System architecture to use
| `locale`                  | str   | `en_US.UTF-8`     | Locale selection
| `timezone`                | str   | `America/Boise`   | Time-zone selection
| `bluetooth`               | bool  | `false`           | Enable or disable bluetooth by default
| `autologin`               | bool  | `false`           | Automatically log the user in or not after boot
| `resolution.x`            | int   | `0`               | Resolution x dimension, e.g. 1920
| `resolution.y`            | int   | `0`               | Resolution y dimension, e.g. 1080
| `type.bootable`           | bool  | `false`           | Host requires a bootloader
| `type.vm`                 | bool  | `false`           | Host is a virtual machine
| `type.iso`                | bool  | `false`           | Enable or disable ISO mode
| `type.develop`            | bool  | `false`           | Host is intended to be used for development
| `type.theater`            | bool  | `false`           | Host is intended to be used for media
| `drives`                  | list  | [ ]               | List of drive objects
| `drives[x].uuid`          | str   |                   | Drive identifier used in `hardware-configuration.nix`
| `nix.cache.enable`        | str   |                   | IP of the local Nix Binary Cache
| `nix.cache.ip`            | str   |                   | IP of the local Nix Binary Cache
| `nix.cache.port`          | int   |                   | Port of the local Nix Binary Cache
| `nix.minVer `             | str   | `25.05`           | Nixpkgs minimum version
| `git.user`                | str   |                   | Git user name to use as global configuration
| `git.email`               | str   |                   | Git email to use as global configuration
| `git.comment`             | str   |                   | Not settable - always `self.rev` (or `"dirty"`) from flake introspection
| `net.gateway`             | str   |                   | Default gateway to use for host e.g. `192.168.1.1`
| `net.subnet`              | str   |                   | Default subnet to use for host e.g. `192.168.1.0/24`
| `net.dns.primary`         | str   | `1.1.1.1`         | Default primary DNS to use for host e.g. `1.1.1.1`
| `net.dns.fallback`        | str   | `8.8.8.8`         | Default fallback DNS to use for host e.g. `8.8.8.8`
| `net.macvlan.subnet`      | str   |                   | Subnet to use for macvlan e.g. `192.168.1.0/24`
| `net.bridge.enable`       | bool  | `false`           | Replace the primary NIC with a virtual network bridge
| `net.bridge.name`         | str   | `br0`             | Name to use for the virtual network bridge
| `net.macvlan.name`        | str   | `host`            | Name to use for the macvlan else `host`
| `net.macvlan.ip`          | str   |                   | IP to use for the macvlan else DHCP will be used
| `net.macvlan.gateway`     | str   |                   | Gateway to use for macvlan e.g. `192.168.1.1`
| `net.macvlan.subnet`      | str   |                   | Subnet to use for macvlan e.g. `192.168.1.0/24`
| `net.macvlan.dns.primary` | str   | `1.1.1.1`         | Primary DNS to use for macvlan e.g. `1.1.1.1`
| `net.macvlan.dns.fallback`| str   | `8.8.8.8`         | Fallback DNS to use for macvlan e.g. `8.8.8.8`
| `net.nic0.name`           | str   |                   | NIC system identifier e.g. ens18, eth0
| `net.nic0.ip`             | str   |                   | IP address to use for this NIC else DHCP, e.g. 192.168.1.12/24
| `net.nic0.gateway`        | str   |                   | Default gateway to use for host e.g. `192.168.1.1`
| `net.nic0.subnet`         | str   |                   | Default subnet to use for host e.g. `192.168.1.0/24`
| `net.nic0.dns.primary`    | str   | `1.1.1.1`         | Default primary DNS to use for host e.g. `1.1.1.1`
| `net.nic0.dns.fallback`   | str   | `8.8.8.8`         | Default fallback DNS to use for host e.g. `8.8.8.8`
| `net.nic1.name`           | str   |                   | NIC system identifier e.g. ens18, eth0
| `net.nic1.ip`             | str   |                   | IP address to use for this NIC else DHCP, e.g. 192.168.1.12/24
| `net.nic1.gateway`        | str   |                   | Default gateway to use for host e.g. `192.168.1.1`
| `net.nic1.subnet`         | str   |                   | Default subnet to use for host e.g. `192.168.1.0/24`
| `net.nic1.dns.primary`    | str   | `1.1.1.1`         | Default primary DNS to use for host e.g. `1.1.1.1`
| `net.nic1.dns.fallback`   | str   | `8.8.8.8`         | Default fallback DNS to use for host e.g. `8.8.8.8`
| `nfs.enable`              | bool  | `false`           | Enable pre-configured nfs shares for this system
| `nfs.entries`             | list  | [ ]               | List of nfs entries
| `services`                | list  | [ ]               | List of Service objects
| `services.x.name`         | str   |                   | Name of the service e.g. `stirling-pdf`
| `services.x.type`         | enum  | `cont`            | Type of service `cont` or `nspawn`
| `services.x.port`         | int   | `80`              | Port to map
| `services.x.user`         | user  |                   | User setttings for the service
| `smb.enable`              | bool  | `false`           | Enable pre-configured nfs shares for this system
| `smb.user`                | str   |                   | Default SMB user if override not given
| `smb.pass`                | str   |                   | Default SMB pass if override not given
| `smb.domain`              | str   |                   | Default SMB domain/workgroup if override not given
| `smb.entries`             | list  | [ ]               | List of SMB entries
| `smb.e..[x].mountPoint`   | str   |                   | Share entry mount point e.g. `/mnt/Media`
| `smb.e..[x].remotePath`   | str   |                   | Share remote path e.g. `192.168.1.2:/srv/nfs/Media` 
| `smb.e..[x].user`         | str   |                   | Share specific user
| `smb.e..[x].pass`         | str   |                   | Share specific pass
| `smb.e..[x].domain`       | str   |                   | Share specific domain
| `smb.e..[x].dirMode`      | str   |                   | Share dir mode
| `smb.e..[x].fileMode`     | str   |                   | Share file mode
| `smb.e..[x].writable`     | str   |                   | Share whether its writable or not
| `smb.e..[x].options`      | str   |                   | Share other options
| `user.name`               | str   | `admin`           | User's user name
| `user.pass`               | str   | `admin`           | User's user name
| `user.fullname`           | str   | `admin`           | User's fullname 
| `user.email`              | str   | `""`              | User's email address
| `user.uid`                | str   | `1000`            | User's id
| `user.gid`                | str   | `100`             | User's gid
