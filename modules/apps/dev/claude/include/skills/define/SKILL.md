# Define
Check the spelling and provide the definition of the word: $ARGUMENTS

## Instructions
Output exactly three lines, nothing more:
- Line 1: The input word in bold, followed by either "is correctly spelled" or "is misspelled".
- Line 2: The CORRECT spelling in bold followed by a brief explanation of the correction (or confirmation if already correct).
- Line 3: The concise definition of the word.

Do not output anything else — no headers, no bullet points, no blank lines between the lines.
